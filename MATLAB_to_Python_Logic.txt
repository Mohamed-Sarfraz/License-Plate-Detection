
This Python logic replicates the MATLAB license plate localization process for a Streamlit app,
manually implementing:

1. Grayscale conversion (weighted sum)
2. Dilation (horizontal)
3. Edge histogram analysis
4. Smoothing (moving average)
5. Dynamic thresholding
6. Bounding region selection based on max gradient columns and rows

The Python version avoids inbuilt functions like cv2.Canny or PIL.ImageOps.

Here’s how you’d structure the key steps in a Streamlit-friendly Python app:

---

1. Convert image to grayscale:
    gray = 0.2989 * R + 0.5870 * G + 0.1140 * B

2. Apply horizontal dilation:
    for each row:
        for each col (1 to cols-2):
            dilated[i, j] = max(gray[i, j-1], gray[i, j], gray[i, j+1])

3. Horizontal edge histogram:
    horz1[i] = sum(abs(I[j, i] - I[j-1, i])) for j in 1 to rows
    if diff > 20, count it

4. Smooth the histogram:
    moving average with window size 41

5. Apply threshold:
    horz[i] = 0 if horz[i] < average
    zero out column in image

6. Repeat 3-5 for vertical direction (rows)

7. Use column/row indices with high edge scores:
    Track rising and falling edge transitions
    Form region pairs

8. Extract probable bounding box:
    Check if max_horz, max_vert lie within any candidate box

9. Mask out everything else and display result.
